# User journeys

## M01 — Public website and navigation
Visitor → audience-specific landing → explore previews or demo → register with referral/campaign context → onboarding.

## M02 — Registration and authentication
Register → verify email → basic identity → choose/create workspace → applicable MFA → onboarding → permitted dashboard. Login → authorize membership → last eligible workspace.

## M03 — Creator onboarding
Basic identity → social account or aspiring path → niche → goals/challenges → commercial preferences → review → activate → progressive enrichment.

## M04 — Creator dashboard
Enter Home → review goals/actions → complete tasks → create content → observe results → discover eligible opportunities → review progress.

## M05 — Social media account management
Add account → set visibility/primary → record observations → optional ownership challenge → review → publish permitted metrics → update/remove/disconnect.

## M06 — Creator analytics and insights
Select account/period → review evidence → compare content → identify insight → approve experiment → record results → update learning.

## M07 — AI Growth Assistant
Ask/receive recommendation → retrieve authorized context → generate source-labelled draft → review/edit → explicit approval for action → record feedback/outcome.

## M08 — Content ideation and planning
Discover → develop → draft → schedule → produce → review → publish manually → associate performance → learn.

## M09 — Creator profile and media kit
Build identity → portfolio/services → customize → create kit → review visibility → publish/share → receive verified commercial enquiries → analyze.

## M10 — Campaign marketplace
Discover → filter/compare → view brief and eligibility → optional AI review → save/apply → revalidate → M11.

## M11 — Applications and invitations
Apply/invite/enquire → prospective collaboration → review/clarify → negotiate → both confirm same version → revalidate → M12 agreement.

## M12 — Collaboration and deliverables
Confirmed proposal → agreement review/acceptance → activate → produce → submit exact versions → review/revise → fulfil → report → operational completion; settlement independent; feedback/portfolio optional.

## M13 — Earnings and commercial management
Agreement/external income → obligations → invoice → payment report → confirm/reconcile/allocate → track expenses → analyze goals; discrepancies M12.

## M14 — Brand onboarding
Create workspace → basic identity/objective → customers/goals/resources → eligible private workspace → enrich catalogue/guidelines/social data → verify → unlock eligible commercial actions.

## Golden end-to-end test
Visitor registers as aspiring Creator → uses manual growth plan and content tools → publishes eligible portfolio/UGC kit → verified Brand creates eligible campaign (M17 pending) → Creator explicitly applies → authorized Brand selects (M18 pending) → both confirm proposal → accept agreement → submit/approve exact deliverable version → handover → record external payment → reconcile → optionally review and showcase work.

The Brand-side campaign creation/selection and dashboards require their own approvals; test fixtures may exercise shared contracts in nonproduction but are not launch substitutes.
